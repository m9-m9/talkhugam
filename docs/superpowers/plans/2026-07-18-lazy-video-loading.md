# 영상 화면·Mux Player 지연 로딩 계획

**목표:** 영상과 관계없는 첫 화면에서 영상 재생 엔진을 내려받지 않아 초기 JavaScript 번들을 줄인다.

## 원인

1. 라우터가 영상 보관함과 재생 화면을 정적으로 import해 앱 시작 시 함께 묶고 있었다.
2. 책 대화 화면이 Mux Player를 정적으로 import해, 영상 라우트만 분리해도 재생 엔진이 초기 번들에 남았다.

## 범위

1. 영상 보관함과 영상 재생 화면을 React Router lazy route로 전환한다.
2. Mux Player adapter를 별도 파일로 분리하고, 재생 UI가 실제로 렌더링될 때만 `React.lazy`로 불러온다.
3. 지연 로딩 중에는 기존 책 로딩 스피너로 `재생기를 불러오고 있어요.`를 안내한다.
4. 영상이 없는 책 대화에서 Mux 모듈을 불러오지 않는 단위 테스트를 추가한다.
5. build 산출물에서 entry와 Mux 재생기 chunk가 분리되는지 확인한다.

## 완료 기준

- 영상 없는 책 대화 렌더링은 Mux Player module을 요청하지 않는다.
- 영상 보관함·재생 페이지는 독립 JavaScript chunk로 생성된다.
- Mux 재생 코드는 별도 chunk로 생성되고 초기 entry에는 포함되지 않는다.
- 기존 영상 재생·오류·재시도 테스트와 전체 품질 검증을 통과한다.
