# 구현·운영 문서 정합성 갱신 계획

**목표:** 실제 코드와 운영 상태가 바뀌어도 README와 운영 문서가 과거 기획·도구 상태를 설명하지 않게 한다.

## 변경

1. README의 UI 라이브러리와 E2E viewport 설명을 실제 의존성·Playwright 설정에 맞춘다.
2. 인증 문서의 상대 일정 표현을 반복 가능한 운영 검증 기준으로 바꾼다.
3. Mux 실연동 테스트가 기본 CI에서 의도적으로 제외되는 이유와 실행 조건을 명확히 한다.

## 완료 기준

- 문서의 기술 스택과 테스트 viewport가 `apps/web/package.json`, Playwright 설정과 일치한다.
- 과거 티켓 번호나 특정 날짜에 의존하는 문구가 남지 않는다.
- 실제 외부 연동 검증과 기본 CI의 역할 차이가 명확하다.
