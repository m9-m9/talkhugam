## Phase 1

- 모바일 우선 웹
- 독서방 최대 6명
- 책별 채팅, 독후감, 답글, 멘션, 알림
- 30초 영상 업로드와 재생
- Kakao, Naver, Google 로그인

## 기술 스택

- React, Vite, TypeScript strict
- Supabase Auth, PostgreSQL, Realtime, Edge Functions
- Mux Video
- TanStack Query, React Hook Form, Zod
- Tailwind CSS, shadcn/ui
- Vitest, Testing Library, Playwright
