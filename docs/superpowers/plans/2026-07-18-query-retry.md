# 초기 조회 실패 재시도 구현 계획

> **에이전트 작업 필수 절차:** 테스트를 먼저 작성하고, 구현 뒤 독립 QA 검토와 전체 검증을 진행한다.

**목표:** 초기 데이터 조회가 실패한 화면에서 사용자가 페이지를 새로고침하지 않아도 다시 시도할 수 있게 한다.

**구조:** 화면별 조회 경계는 기존 상태 관리 방식을 유지한다. 온보딩은 재조회 키로 프로필 요청을 다시 실행하고, TanStack Query를 쓰는 프로필 편집·독서방 상세는 `refetch()`로 다시 요청한다. 로딩 상태에는 Book Loading Spinner를, 오류 상태에는 오류 안내와 재시도 버튼을 각각 표시한다.

**기술:** React, TypeScript strict, TanStack Query, Vitest, Playwright

---

### 작업 1: 실패 흐름 테스트

- [x] 온보딩 프로필 조회 실패 뒤 `다시 시도`가 새 요청을 만드는 테스트를 작성한다.
- [x] 프로필 편집 조회 실패 뒤 `다시 시도`가 `refetch()`를 호출하는 테스트를 작성한다.
- [x] 독서방 상세의 책 목록 조회 실패 뒤 `다시 시도`가 `refetch()`를 호출하는 테스트를 작성한다.
