# 책방 생성 완료 직접 공유 설계

## 목적

책방을 만든 직후 초대 코드를 따로 전달해야 하는 단계를 줄인다. 완료 화면에서 카카오톡, 인스타그램, 페이스북에 바로 초대 링크를 공유하고, 초대 코드 복사 성공 여부는 토스트로 알린다.

## 범위

- 대상 화면: `/rooms/create`에서 책방 생성 성공 후 보이는 완료 화면
- 카카오톡, 인스타그램, 페이스북 공유 버튼을 완료 화면에 직접 노출한다.
- 기존 `초대 코드 복사하기` 버튼은 유지하고, 성공 또는 실패 토스트를 표시한다.
- 생성 직후 받은 초대 토큰으로 참여 링크를 만든다.

## 화면과 상호작용

1. 완료 화면의 초대 코드 카드 아래에 `친구 초대하기` 제목과 같은 폭의 카카오톡, 인스타그램, 페이스북 버튼을 둔다.
2. 카카오톡 버튼은 Kakao JavaScript SDK로 초대 문구와 참여 링크를 전달한다. JavaScript 키가 없거나 SDK 호출에 실패하면 기기 기본 공유를 시도한다.
3. 인스타그램 버튼은 초대 문구와 참여 링크를 클립보드에 복사한 뒤 인스타그램을 연다. 성공 토스트는 인스타그램에서 붙여넣어 보내도록 안내한다.
4. 페이스북 버튼은 Facebook sharer에 참여 링크를 전달한다.
5. `초대 코드 복사하기`는 초대 코드만 복사하고, 성공 시 `초대 코드를 복사했어요.`, 실패 시 `초대 코드를 복사하지 못했어요.` 토스트를 표시한다.
6. `나중에`는 기존처럼 책방 목록으로 이동한다.

## 데이터와 보안

- `create_room_invite` RPC는 초대 코드와 함께 일회성 평문 토큰을 이미 반환한다.
- 현재 `CreatedRoomInvite`가 토큰을 버리므로, 생성 결과 타입과 mapper에 `token`을 포함한다.
- 토큰은 완료 화면의 React 상태에서만 사용하며 DB, 분석 이벤트, 로그, URL 이외의 저장소에 기록하지 않는다.
- 참여 링크 형식은 기존 초대 흐름과 같은 `/rooms/join?invite=<token>`을 사용한다.

## 컴포넌트 경계

- `CreateRoomPage`: 생성 결과와 방 이름을 완료 화면에 전달한다.
- `RoomCreatedPage`: 완료 화면 전용의 공유 행동, 토스트 상태, 채널 버튼을 담당한다.
- `features/invite-sharing`: 기존 `createInviteShareData`, `shareInviteWithKakao`, 플랫폼 URL, 복사 함수를 재사용한다.
- 공유 토스트는 SEED Snackbar로 완료 화면에 한 번만 표시한다.

## 반응형과 접근성

- 320px에서 세 버튼은 같은 폭을 유지하고 텍스트·아이콘이 겹치지 않는다.
- 모든 공유·복사 버튼은 최소 44px 터치 영역과 접근 가능한 이름을 가진다.
- 토스트는 `role=status`로 읽히며, 공유 창을 연 뒤 포커스를 강제로 이동시키지 않는다.

## 검증

- 단위 테스트: 생성 결과의 토큰 보존, 링크 생성, 카카오 SDK 및 fallback, 인스타그램 복사, 페이스북 URL, 복사 성공·실패 토스트.
- 브라우저 테스트: 완료 화면의 320px·640px 정렬, 버튼 동작, 토스트, 오버플로 없음.
- 전체 웹 테스트, 빌드, E2E를 실행한다.

## 제외 범위

- 인스타그램 게시물 작성창에 텍스트를 자동 입력하는 기능은 웹 플랫폼에서 지원하지 않으므로 포함하지 않는다.
- Facebook App ID, 별도 Meta 로그인, 새 DB migration은 필요하지 않다.
