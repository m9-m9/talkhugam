# 책방 경험과 권한 설계

## 목표

책방의 읽기 상태, 운영 권한, 메시지 추가, 영상 기록을 사용자가 예측 가능한 위치에서 찾고 조작할 수 있게 한다.

## 결정

### 독서 상태

- 개인 진행률은 `현재 / 전체 쪽`, 퍼센트, 얇은 진행 막대로 표시한다.
- 개인 완독은 날짜 없이 `완독` 배지로 표시한다.
- 책방 목록, 책방 상세의 읽는 책, 내 정보의 읽는 책은 동일한 상태 표현을 사용한다.
- 책 대화 관리에서 개인 진행률과 완독 기록을 함께 수정한다.

### 책방 역할

| 역할 | 초대·요청 | 읽을 책·제안 | 구성원·역할 | 방 설정 |
| --- | --- | --- | --- | --- |
| 방장 | 생성·승인 | 추가·승인 | 변경·내보내기·방장 이양 | 가능 |
| 운영자 | 생성·승인 | 추가·승인 | 불가 | 불가 |
| 참여자 | 요청 | 제안 | 불가 | 불가 |

- 멤버 내보내기, 역할 변경, 방장 이양은 방장만 수행한다.
- 참여자는 책방 상세에서 방장만 확인한다.
- 역할을 바꾸는 화면은 방장 전용 `방 정보 > 구성원 관리` 한 곳이다.
- 초대 요청과 읽을 책 제안은 방장과 운영자 모두 처리할 수 있다.

### 방 정보 허브

- 책방 상세 헤더의 우측 `...`는 `방 정보`로 이동한다.
- 책방 상세의 별도 `새 책` 행동은 제거한다.
- `방 정보`는 역할에 따라 `초대 관리`, `읽을 책 관리`, `구성원 관리`, `방 설정`을 노출한다.
- 참여자는 방장, 구성원, 나가기만 본다.
- 운영자는 초대·읽을 책·요청 관리를 본다.

### 메시지 추가와 영상

- `+` 바텀시트에는 `라벨 등록`, `영상 기록` 두 행동만 남긴다.
- `라벨 등록`은 페이지 또는 챕터를 선택하고 입력한 값을 대화에 추가한다.
- 완독 기록은 `책 대화 관리`로 이동하고, 책방 초대는 `방 정보`로 이동한다.
- `+ > 영상 기록`은 현재 책 대화의 영상 기록으로 이동한다.
- 새 `/rooms/:roomId/videos`는 책방의 모든 책 영상 기록을 모아 보여 주고, 책별 필터를 제공한다.
- 책방 상세에는 최근 영상 미리보기와 책방 전체 영상 기록 진입점을 둔다.

## 데이터와 권한

- `member_role` enum에 `manager`를 추가한다.
- 기존 `create_book_chat`은 활성 멤버 전체 허용에서 방장·운영자 허용으로 변경한다.
- 초대 RPC는 방장·운영자 허용으로 변경한다. 초대 폐기도 같은 역할을 사용한다.
- 책 제안 요청은 별도 테이블과 RPC로 저장하며, 요청 상태는 `pending`, `approved`, `rejected`다.
- 초대 요청은 기존 알림/요청 흐름을 방장·운영자 대상 모델로 확장한다.
- 모든 권한 판단은 PostgreSQL RPC에서 재검증한다. UI 표시만으로 권한을 판단하지 않는다.

## 검증

- 단위 테스트: 역할 권한 매퍼, 진행률·완독 상태 모델, 영상 그룹화/필터.
- React 테스트: 방 정보 역할별 CTA, 메시지 추가 축소, 읽는 책 상태 표현.
- pgTAP: 방장·운영자·참여자의 초대, 책 추가, 역할 변경, 책 제안 승인·거부 허용/거부 케이스.
- Playwright: 320px와 640px에서 방 정보, 메시지 추가, 책방/책별 영상 기록, 진행률·완독 흐름.
