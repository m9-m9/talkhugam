# 책 대화 조회 오류 상태 구현 계획

> **에이전트 작업 필수 절차:** 실패 테스트를 먼저 작성하고, 구현 뒤 독립 QA 검토와 웹 검증을 진행한다.

**목표:** 감상 또는 영상 목록 조회가 실패했을 때 실제 빈 대화로 잘못 안내하지 않고, 사용자가 바로 재시도할 수 있게 한다.

**구조:** 두 조회가 모두 성공하고 메시지가 없을 때만 빈 상태를 표시한다. 한 조회라도 실패하면 실패 종류별 안내와 재시도 버튼을 표시한다. 실패하지 않은 조회 결과가 있으면 그대로 유지한다.

**기술:** TanStack Query, React Testing Library, Vitest, Playwright

---

### 작업 1: 실패 상태 회귀 테스트

- [x] 감상 조회 실패가 빈 상태 대신 재시도 안내를 표시하는 테스트를 작성한다.
- [x] 영상 조회 실패가 빈 상태 대신 재시도 안내를 표시하는 테스트를 작성한다.

### 작업 2: 화면 상태 구현

- [x] 감상·영상 조회 오류를 각각 구분하는 안내 문구를 구현한다.
- [x] 오류 상태에서 두 조회를 다시 요청한다.
- [x] 오류 상태에서는 빈 대화 카드를 표시하지 않는다.
- [x] 한 조회만 성공했을 때 이미 받은 메시지를 오류 안내와 함께 유지한다.
- [x] 재시도 중에는 책 로더와 비활성화된 재시도 버튼을 표시한다.

### 작업 3: 검토와 검증

- [x] 독립 QA 에이전트가 부분 성공·오류·재시도 흐름을 검토한다.
- [x] lint, typecheck, test, build, Playwright 검증을 실행한다.
