# 영상 재생 조회 오류 복구 구현 계획

## 목표

영상 보기 화면에서 잘못된 주소, 영상 정보 조회 실패, 재생 권한 토큰 조회 실패를 구분해 안내하고, 사용자가 안전하게 재시도하거나 영상 기록으로 돌아갈 수 있게 한다.

## 구현 범위

1. `getVideoPost`가 없는 영상은 오류가 아닌 `null`로 반환하도록 조회 계약을 정리한다.
2. 영상 없음, 영상 정보 조회 실패, 재생 토큰 조회 실패 화면을 각각 분리한다.
3. 각 오류 화면은 해당 실패 query만 다시 조회하고, 재시도 중에는 책 로딩 스피너와 비활성화된 버튼을 유지한다.
4. 잘못된 주소와 오류 화면에서 영상 기록으로 돌아가는 CTA를 제공한다.
5. RTL에서 상태별 문구·재시도·복귀 동작을 검증하고, Playwright로 실제 라우트의 잘못된 영상 복귀 흐름을 확인한다.

## 완료 기준

- 존재하지 않는 영상은 재생 실패로 오인되지 않고 보관함 복귀 CTA를 제공한다.
- 영상 정보와 재생 토큰 실패 문구가 서로 다르다.
- 재시도 중 중복 클릭이 막히고 책 로딩 스피너가 표시된다.
- 관련 Vitest, Playwright, lint, typecheck, build가 통과한다.
