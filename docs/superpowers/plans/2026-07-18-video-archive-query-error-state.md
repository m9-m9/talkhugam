# 영상 보관함 조회 오류 상태 구현 계획

## 목표

영상 목록 요청 실패를 “첫 영상 올리기” 빈 상태와 구분한다. 사용자가 오류 원인을 오해하지 않고 즉시 재시도할 수 있게 하며, 이전에 불러온 영상은 오류가 나더라도 유지한다.

## 완료 기준

- 초기 영상 목록 요청 실패 시 `영상 기록을 불러오지 못했어요. 다시 시도해 주세요.`와 재시도 버튼을 표시한다.
- 목록 조회 오류에서는 `첫 영상 올리기` 빈 상태를 표시하지 않는다.
- 재시도 중에는 책 로딩 스피너와 진행 문구를 표시하고 재시도 버튼을 비활성화한다.
- 이전에 조회된 영상이 있는 상태에서 다음 요청이 실패하면 영상 목록을 숨기지 않는다.
- 재시도 성공 후 데이터가 없으면 빈 상태를 정상적으로 표시한다.

## 검증 계획

- Vitest + React Testing Library로 오류, 재시도, 재시도 중 비활성화와 이전 목록 유지 시나리오를 테스트한다.
- `lint`, `typecheck`, 전체 Vitest, 프로덕션 build, Playwright 흐름을 실행한다.
