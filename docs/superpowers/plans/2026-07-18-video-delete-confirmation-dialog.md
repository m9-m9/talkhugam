# 영상 삭제 확인 시트 통일 계획

**목표:** 브라우저 기본 확인창 대신 Talk후감 공용 확인 시트로 영상 삭제를 명시적으로 확인한다.

## 원인

1. 영상 삭제만 `window.confirm`을 사용해 앱의 계정 삭제 시트와 시각·키보드 동작이 달랐다.
2. 기본 확인창은 바깥 클릭, Escape, 포커스 복귀 같은 웹 UI 동작을 일관되게 제어할 수 없었다.

## 범위

1. 위험 작업용 공용 확인 시트를 추가한다.
2. 대화상자 포커스 순환 로직을 공용 UI 기반으로 분리하고 계정 삭제 시트도 공유한다.
3. 영상 삭제 버튼은 먼저 확인 시트를 열고, 확인 이후에만 삭제 요청을 시작한다.
4. Escape·바깥 클릭·포커스 복귀를 단위와 Playwright 검사로 확인한다.

## 완료 기준

- 삭제 확인 전에는 영상 삭제 요청이 실행되지 않는다.
- 취소, Escape, 바깥 클릭은 삭제 없이 시트를 닫는다.
- 화면 전환과 오류 재시도 흐름은 기존과 동일하게 유지된다.
