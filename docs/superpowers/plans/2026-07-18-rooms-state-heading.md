# 독서방 목록 상태별 제목 구조 계획

**목표:** 독서방 목록이 로딩·빈 목록·오류·목록 표시 중 어느 상태여도 접근 가능한 섹션 제목을 유지한다.

## 원인

1. `section`은 `recent-rooms-heading`을 참조했지만 제목은 독서방이 있을 때만 렌더링됐다.
2. 빈 목록·로딩·오류 상태에서 스크린 리더는 섹션의 이름을 찾을 수 없었다.
3. 기존 화면 테스트는 이전 렌더 결과를 정리하지 않아 상태별 검증을 추가하기 어려웠다.

## 범위

1. 제목을 목록 컴포넌트 밖의 페이지 섹션으로 이동한다.
2. 목록·빈 목록·로딩·오류 상태에서 제목이 모두 렌더되는 단위 테스트를 추가한다.
3. 테스트마다 렌더 결과를 정리해 상태별 테스트가 서로 영향을 주지 않게 한다.

## 완료 기준

- `aria-labelledby`가 가리키는 제목이 모든 목록 상태에 존재한다.
- 독서방 목록과 빈·로딩·오류 상태 테스트가 모두 통과한다.
- 전체 웹 품질 검증과 브라우저 UI 검사를 통과한다.
